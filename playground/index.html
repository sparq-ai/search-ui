Sparq Search UI — Playground

Every page runs against the in-memory mock client (api-host="mock:") — no credentials needed. Each page doubles as living documentation for one scenario.

  • Basic — searchbox + stats + items + pagination
  • Facets — filters, sort, range, refinement chips, full search page
  • Templates — customer-defined item markup via <template>
  • Theming — --sparq-* tokens and ::part() restyling
  • SSR takeover — server-rendered fallback replaced by JS render
  • Infinite scroll — <sparq-items-infinite auto>
  • Hooks — transformResponse, queryHook, suggestionsSource, item-click analytics
